# Firebase & Google OAuth Setup Guide

This guide walks through configuring Firebase Authentication, Google Identity Provider, and Cloud Firestore for **HB Plus Workspace**.

---

## 1. Create Firebase Project

1. Navigate to the [Firebase Console](https://console.firebase.google.com/).
2. Click **Add Project** and name it `hbplus-workspace` (or your preferred identifier).
3. Disable or enable Google Analytics according to your preference, then click **Create Project**.

---

## 2. Register Web Application

1. In the Project Overview page, click the **Web icon (`</>`)** to add a web app.
2. App nickname: `HB Plus Workspace Web`.
3. Do not check "Firebase Hosting" (Netlify will host the frontend).
4. Click **Register app**.
5. Copy the configuration credentials into your `.env` file:
   ```env
   EXPO_PUBLIC_FIREBASE_API_KEY=AIzaSy...
   EXPO_PUBLIC_FIREBASE_AUTH_DOMAIN=hbplus-workspace.firebaseapp.com
   EXPO_PUBLIC_FIREBASE_PROJECT_ID=hbplus-workspace
   EXPO_PUBLIC_FIREBASE_STORAGE_BUCKET=hbplus-workspace.appspot.com
   EXPO_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=123456789012
   EXPO_PUBLIC_FIREBASE_APP_ID=1:123456789012:web:abcdef...
   ```

---

## 3. Enable Google Authentication Provider

1. In the Firebase left navigation, select **Build > Authentication**.
2. Click **Get Started**.
3. Under the **Sign-in method** tab, select **Google**.
4. Toggle **Enable**.
5. Set the **Project support email** to your administrative email.
6. Open **Web SDK configuration**:
   * Note the **Web client ID** generated by Google.
   * Add this to your `.env` as `EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID`.
7. Click **Save**.

---

## 4. Authorize Deployment Domains

In Firebase Console under **Authentication > Settings > Authorized domains**:
1. Add `localhost` (pre-configured).
2. Add your Netlify production domain (e.g., `hbplus-workspace.netlify.app` or custom domain `workspace.hbplus.fit`).
3. Click **Add domain**.

> [!IMPORTANT]
> If your production domain is not listed under Authorized Domains, Google Sign-In popups and redirects will fail with `auth/unauthorized-domain`.

---

## 5. Configure Firestore Database & Security Rules

1. In Firebase Console, select **Build > Firestore Database** and click **Create database**.
2. Select standard production mode and choose your geographical region.
3. Once provisioned, navigate to the **Rules** tab and paste the contents of `firestore.rules`:
   ```javascript
   rules_version = '2';
   service cloud.firestore {
     match /databases/{db}/documents {
       function isCompany() {
         return request.auth != null
           && request.auth.token.email_verified == true
           && request.auth.token.email.matches('.*@hbplus\\.fit');
       }

       match /users/{uid} {
         // Users can read only their own profile; client writes are disabled
         allow read: if isCompany() && request.auth.uid == uid;
         allow write: if false;
       }

       match /{document=**} {
         allow read, write: if false;
       }
     }
   }
   ```
4. Click **Publish**.

### Assigning Administrator Roles:
Because client-side writes are prohibited for security, assign roles manually:
1. In Firestore Database under the **Data** tab, click **Start collection**.
2. Collection ID: `users`.
3. Document ID: The user's Firebase UID (e.g. from the Authentication tab).
4. Add field: `role` (string) = `"admin"`.

---

## 6. Native App Configuration (Android & iOS)

### Android
1. In Project Settings, click **Add app > Android**.
2. Package name: `fit.hbplus.workspace` (must match `android.package` in `app.json`).
3. Add your SHA-1 fingerprint (from your debug/release keystore):
   ```bash
   keytool -list -v -keystore "%USERPROFILE%\.android\debug.keystore" -alias androiddebugkey -storepass android -keypass android
   ```
4. Download `google-services.json` and place it in the project root.
5. In `app.json`, set:
   ```json
   "android": {
     "package": "fit.hbplus.workspace",
     "googleServicesFile": "./google-services.json"
   }
   ```

### iOS
1. In Project Settings, click **Add app > iOS**.
2. Bundle ID: `fit.hbplus.workspace` (must match `ios.bundleIdentifier` in `app.json`).
3. Download `GoogleService-Info.plist` and place it in the project root.
4. Copy the `REVERSED_CLIENT_ID` or iOS Client ID into `.env` as `EXPO_PUBLIC_GOOGLE_IOS_CLIENT_ID`.
5. In `app.json`, set:
   ```json
   "ios": {
     "bundleIdentifier": "fit.hbplus.workspace",
     "googleServicesFile": "./GoogleService-Info.plist"
   }
   ```
